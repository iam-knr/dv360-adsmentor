# P4-10a bulk edit, SDF, saved views and charts: what is not done

Branch `p4-10a-bulk-sdf`, module 11 tasks T11-01 to T11-13 (`docs/specs/modules/11-bulk-sdf-optimisation.md`). Experiments (module 17) are P4-10b; the Intelligence suggestions, the Investigate drawer and the recommendation generators (T11-14 to T11-16) are P4-11. Migration `0010_p4_10a_bulk_charts` only adds enum values (`BulkAction.EDIT_TARGETING`, `ChartCardKind` `KPI`, `BUILT_IN`, `NOTE`).

## A. Not done in module 11

| # | Gap | Task | Size |
|---|---|---|---|
| A1 | SDF layouts follow the module's simulator definitions (Q-11-01). Line item columns the simulator does not model are exported blank and ignored on upload (a changed value raises the BLK-028 warning): View Frequency, Custom Bidding Algorithm Id, Public Inventory Exchanges, Deal Ids, Deal Group Ids, Targeting Template Id, Geography Radius, Location List Ids, Make Model, Negative Keyword List Ids, Video Player Size, Content Duration, Livestream, Rewarded, Brand Suitability, Subtype, Mobile App columns (read only after create), YouTube columns | T11-04 | M |
| A2 | Audience columns of the line item file hold the ids stored in the targeting state (row ids), not the public ids of the audience lists | T11-04 | S |
| A3 | Ad Groups and Ads files are exported in full. An upload applies only Name, Status and Bid Value of existing ad groups, and Status of existing ads; new ad groups and ads are refused (BLK-005). Ad name edits raise BLK-028 | T11-06 | M |
| A4 | Media Products is exported from `InventorySourceDeal` (Δ-11-4); an upload of that file is not recognised as a media products file (BLK-021) instead of being ignored with a warning | T11-06 | S |
| A5 | Partner-scope SDF Upload (C-11-19, Δ-11-15) is not built: dialogs open per advertiser | T11-06 | S |
| A6 | SDF files go to the server as a multipart request (5 MB per file is checked after the body is read), not through the signed upload flow (Q-11-09). Vercel's 4.5 MB body limit applies | T11-06 | S |
| A7 | Result and download files live in the creative file store: memory unless `BLOB_READ_WRITE_TOKEN` exists (owner item P-08). After a server restart a download link answers 404 "The file is no longer available." | T11-05 | S |
| A8 | The "Download QA" file runs the form validators on each stored entity. Cross-entity matrix checks (IO-093, IO-094, LI-064, AG-005, creative eligibility) and engine `CONF.*` warnings (Q-11-07) are not added | T11-05 | M |
| A9 | The validation registry's BLK table is still empty (`lib/validation/rules/bulk.ts`). BLK-003, BLK-020..BLK-035 live in `lib/sdf/rules.ts` and `lib/bulk/messages.ts`, so `docs/specs/validation.md` and its sync test are unchanged | T11-06 | S |
| A10 | Bulk jobs run in the request until the time budget (8 s) ends, then the worker route `/api/bulk/run` (Bearer `CRON_SECRET`) and the Bulk status page resume them. No scheduled trigger calls the worker yet (add it to `engine-tick.yml` or a second workflow). At most one running job per advertiser is not enforced; a lease on the job row keeps two callers off the same job | T11-02 | S |
| A11 | Bulk edit panels use compact value editors, not the module 10 editors in a stacked slide-over: Geography takes region codes as text, Audience lists take Google audience ids as text, Apps and URLs take URLs as text. | A12 | Bulk apply of a targeting template needs the template to exist: there is no template list page yet (module 10), so the picker reads `TargetingTemplate` rows only. The template's inventory quality and exchanges are not applied, only targeting and Optimized targeting | T11-07 | S |
| A13 | Duplicate keeps the names of children (`Copy of` is only on the top row) and does not offer a parent picker dialog: the target parent is a typed public id | T11-03 | S |
| A14 | Column views cover the columns the grids hold today (no Win rate, Pacing %, Bid strategy, KPI actual columns), so Pacing and Optimization are short sets. The menu is on the Campaigns list, the IO list and the standalone line item grid; the line item grid embedded in an IO or campaign tab has no menu. Custom views are per person and per advertiser; there is no drag reorder (up / down buttons) | T11-08 | M |
| A15 | Charts: card ⋮ has Remove, Move earlier and Move later (no drag handle and no Edit dialog). Built-in cards added through Add show a placeholder text; the five built-ins of the strip are still the empty-state cards of module 06. The chart strip is on the campaign page and the IO page only, not on the IO list or LI list. Dimensions Creative and Format are not available in chart data | T11-09 | M |
| A16 | The chart prompt parser is the canned grammar (Q-11-08); no LLM | T11-10 | S |
| A17 | Shared chart view: Share saves the current cards under the view key `shared` and copies `?cv=chart:{userId}`. Opening it as a second person in a browser needs a second person who resolves to the same sandbox (same limit as `docs/gaps/p4-07.md` 8); the service rules are covered by `tests/charts/charts.db.test.ts` | T11-09 | S |
| A18 | Seed: no SDF fixture sets (good and broken) are generated; tests build theirs from a download. Seeded jobs have no result files | T11-11 | S |
| A19 | Playwright covers PW-11-01, 02, 07, 10, 12, 15, 16. The other outlines are covered by service tests (list in the PR) | T11-12 | S |
| A20 | Every bulk change runs through the single-entity services. A line item that fails its own validation (for example a seeded line item with a stale pacing) fails the same way in bulk, and the service may also normalise unrelated fields on save (the SDF rename test sees a Pacing type change on a line item created outside the form) | T11-03 | S |
