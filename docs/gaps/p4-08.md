# P4-08 planning and reach planner: what is not done

> Updated by plan-parity (`docs/gaps/plan-parity.md`): rows 2, 6, 7 and 10 are closed there; row 8 is unchanged; row 9 now returns to the two default statuses (Planned, Trafficked) because Archived is a third, unticked status.

Branch `p4-08-planning`, module 04 (`docs/specs/modules/04-planning.md`). Everything below is a known gap or a decision, with the reason.

| # | Gap or decision | Reason / where it goes |
|---|---|---|
| 1 | The plan forecast parameters live in `lib/planning/params.ts`, not in `engine/params.json` under `plan` (DELTA-04-9), and `forecastPlan` is in `lib/planning`, not `lib/engine` | The params file has a schema owned by the engine session (P3-08). Move both when the engine owner adopts them |
| 2 | **Closed by plan-parity.** Plan row targeting is locations plus free-text audience tags, not the shared targeting panel (2.4). **Create campaign** copies only a GEOGRAPHY include to the line item drafts | The shared targeting panel is draft-bound to line items (RT 5.4); a plan-mode variant is not built |
| 3 | A TV channel on a plan is stored and listed but not forecast by a separate TV model (Q4) | Low value for the classroom exercise |
| 4 | Cross-media digital reach is estimated from `SimDailyMetric` impressions, not from `SimReachSnapshot` (4.9) | `SimReachSnapshot` has no per-IO rows yet (engine, `docs/gaps/p3.md`) |
| 5 | Cross-media reports write no `ChangeGroup` (spec 4.10 says `REPORT`) | There is no `REPORT` change-log registry until P4-12 (same as `docs/gaps/p4-07.md` #1) |
| 6 | **Closed by plan-parity.** The New plan wizard (explore 19, two steps) is replaced by direct create with the defaults of 4.2 | Matches the spec's own PLN-001 default and keeps AC-04-4 |
| 7 | **Closed by plan-parity.** Plan dates, row dates and copy dates are native date inputs, not `DvDateRange` | `DvDateRange` needs a preset set; same as `docs/gaps/p4-07.md` #5 |
| 8 | Demographics are a dialog of gender and age checkboxes, not a dropdown pair | Same data (`ageMin`, `ageMax`, genders), fewer open popovers |
| 9 | Unchecking every status in the Plans filter and pressing Apply returns to both statuses instead of blocking | The shared `DvFilterBar` treats an empty selection as "remove the filter" |
| 10 | **Closed by plan-parity.** Forecast is on Save only (Q5): no live preview through `opts.draft` | Latency is fine, but the stale notice covers the spec |
| 11 | The Plans list shows an extra **Status** column (Planned or Trafficked) | AC-04-18 needs the Trafficked chip in the list |
| 12 | The "Learn more" link on the Cross-media welcome state points at an in-page anchor | There is no help site to link to |
| 13 | The Cross-media picker lists only advertisers, campaigns and IOs of the sandbox, with spend from `SimDailyMetric` of all available history, not a strict 24-month window | The simulator has less than 24 months of history (C-04-7) |
| 14 | `FormFrame` got a `wide` prop and `DvModal`'s primary action a `disabled` prop | Needed for the full-width plan page and the "Done disabled until a selection" dialogs. Backwards compatible |
