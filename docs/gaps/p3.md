## C. Deviations worth keeping in mind

Taken from the PR bodies; none block Phase 4, all are decided and recorded in the PRs.
- Prisma config lives in `prisma.config.ts`; `publicId` default is `next_public_id()`; RLS is role based (`app_tenant`, `app_engine`), not the `app.bypass_rls` setting (#1, #2).
- `DiagStage` follows ENG 3.5, hourly metric rows are totals only (RC-021, RC-022, #2).
- `SessionUser.appRole` is `user | admin | super_admin`; idle time is `User.lastSeenAt`; the 5th failed sign-in shows SIM-002 (#7).
- `SimState` is one JSON string per advertiser; a batch is one transaction of up to 24 ticks (#15).
- Rates are percent numbers; date presets are duplicated in `lib/metrics/date-range.ts` with a property test (#10).
- Seed uses 3 campaigns per advertiser and 36 line items per sandbox (#6).
