### 4.7 Convert plan to campaign

```ts
// RT 8.10: convertPlan(id, { target: 'CAMPAIGN'|'IO'; campaignId?: Id })   (public docs)
convertPlan(input: { id: Id; target: 'CAMPAIGN'|'IO'; campaignId?: Id } & WriteMeta): Promise<Result<{ campaignId: Id; ioId: Id; lineItemIds: Id[] }>>
```
Mapping:
- Campaign (when `target = CAMPAIGN`): name = plan name, goal `AWARENESS` if channels Digital only and no conversion rows, else `ONLINE_ACTION`; planned spend = `totalBudget`; flight = plan dates; status `ACTIVE` (campaign has no Draft, VAL 4.2).
- IO: name = "{plan name} IO", type `STANDARD`, objective `NONE` (all LI types allowed, MX-02), one budget segment (plan dates, amount `totalBudget`), pacing Flight Even, status `DRAFT`.
- One line item per `PlanRow`: type `DISPLAY` (Open auction), status `DRAFT`, name = row name, flight = row dates, budget = `budgetNet`, bid `FIXED_BID` at the row CPM (or max CPM), targeting copied from the row (`TargetingAssignment` with `ownerType = LINE_ITEM`), deal reference if the row has a deal.

### 4.8 Forecast formulas (the contract the engine must provide)

This module needs `engine.forecastPlan(world, plan)` (pure, deterministic from `sandboxSeed + plan.inputsHash`; C-04-3). It is the plan counterpart of `engine.forecast` (ENG 1.6). Proposed math, all parameters in `engine/params.json` under `plan` (DELTA-04-9):

```
For each row r:
  cpm_r        = clearingCpm(format(r)) * market.priceIdx * buyingMethodPremium[r.method]      // ENG 2.5, 2.6; open auction 1.0, preferred 1.10, private 1.05, PG fixed rate from deal
  fee_r        = 1 + feePct_r
  impr_r       = (budgetNet_r / cpm_r) * 1000                                                   // billable units
  U_r          = basisPopulation(country, reachBasis) * demoShare(demographics) * audienceShare(r.targeting)
  onTargetImpr = impr_r * onTargetShare                                                        // onTargetShare = demographic match, default 0.85
  reach_r      = U_r * (1 - (1 + onTargetImpr / (k * U_r)) ^ (-k)),  k = 1.5                    // ENG 9.5
  reachPct_r   = reach_r / U_r ; freq_r = onTargetImpr / reach_r
  TRP_r        = reachPct_r(%) * freq_r                       // same identity as the plan level
Plan:
  reach        = U * (1 - prod(1 - reach_r / U_r)),  U = 1.15 * max(U_r) capped at basis population   // ENG 9.5 overlap
  avgFrequency = sum(onTargetImpr_r) / reach
  TRPs         = onTargetReachPct * avgFrequency          // identity, example 76.5 x 7.85 = 600.5
  totalCpm     = sum(budgetNet_r * fee_r) / sum(impr_r) * 1000    // identity: 57,476.18 / 28.7M x 1000 = 2.00
  CPP          = budget / TRPs                                    // identity: 57,476.18 / 600 = 95.79
  viewableCpm  = totalCpm / viewableShare ; viewabilityRate = viewable / measurable (ENG 2.5)
  CPA          = budget / (impr * ctr * clickCvr + viewableImpr * postViewCvr)  or null when no conversion params apply
  population   = { census, digital, tv, youtube } from PlanCountry
```
Row TRPs use the same identity at row level. Tabs: Reach = the formula evaluated at 50% to 150% of budget; TrueView = views = YT impressions x VTR; Conversions weekly; Demographics = split of reach by `demoShares`; Devices = split by the device shares of ENG 2.3.
